# 08. Gap Analysis

## What exists
- CPO apps give live status on their own network (Tata, Ather Grid, ChargeZone, Jio-bp pulse).
- Aggregators (ElectricPe, Statiq, Kazam) list many chargers and feed Google Maps.
- Google Maps shows basic find-and-status for 8,000+ stations.
- Tata has a wait timer and slot booking, on its own network.

## What is missing
| Gap | Evidence |
|---|---|
| Reliable live status across all networks in one app | No player offers it (research finding); users keep 3-4 apps |
| Accurate "available" vs broken | Pain points 1, 4, 10, 11 |
| Wait-time prediction | Only Tata's timer found |
| Slot booking beyond one network | Rare |
| Tier-2 and tier-3 coverage | Thin, per research |
| One payment method, no wallets | Pain point 3 |

## Main risk
A plain "station finder" competes with Google Maps (free, already integrated with the aggregators) and with funded players (Statiq USD 43M+). That is not a winnable position on its own.

## Where the concept can differ
1. **Trust over coverage:** verified status, last-confirmed timestamps, downtime counters.
2. **Tier-2 and tier-3 depth**, for example Gujarat, where big players have little data.
3. **Booking plus payment in one app.**
4. Possibly the 2W and 3W segment (connector filtering, pain point 12).

## Weak points to state openly
- Needs user density for crowdsourced status.
- Self-listed data is not machine-verified.
- Booking has a no-show problem.
- Competitors could add the same features.
